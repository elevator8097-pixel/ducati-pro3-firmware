# Ducati PRO-III — Мінімальна прошивка v0.1.0

## Що робить ця прошивка
- ✅ Читає газ (throttle) через ADC
- ✅ Читає датчики Холла мотора
- ✅ Керує BLDC мотором (6-step комутація)
- ✅ Читає гальмо (відключає мотор)
- ✅ Захист від перенапруги (>42V) і розрядки (<32V)
- ✅ Плавний розгін (рамп)

## Як зібрати

### 1. Встанови компілятор
```bash
# Linux/WSL:
sudo apt install gcc-arm-none-eabi

# Windows: завантаж з
# https://developer.arm.com/downloads/-/arm-gnu-toolchain-downloads
```

### 2. Завантаж GD32F10x бібліотеку
```
https://github.com/CommunityGD32Cores/GD32F10x_Firmware_Library
```
Розпакуй в папку `lib/GD32F10x_standard_peripheral/`

### 3. Завантаж linker script
```
GD32F103x8.ld — для чіпа з 64KB flash
```
Знайди в прикладах GD32 або STM32F103C8 (сумісний)

### 4. Збери
```bash
make
```
Отримаєш файл `ducati_pro3.bin`

## Як залити

### Підключення ST-Link v2 → плата (пади IO G)
```
ST-Link    Плата (пади вгорі справа "IO G")
─────────────────────────────────────────
3.3V  ──→  3.3V (якщо не живиться від батареї)
GND   ──→  G
SWDIO ──→  IO (перший пад)
SWCLK ──→  другий пад
```

### Команда заливки
```bash
openocd -f interface/stlink.cfg \
        -f target/stm32f1x.cfg \
        -c "program ducati_pro3.bin verify reset exit 0x08000000"
```

Або через make:
```bash
make flash
```

## Важливо перед заливкою

### Перевір коефіцієнт дільника батареї
Виміряй мультиметром реальну напругу батареї і порівняй з тим що читає ADC.
В `battery.c` є константа `BAT_DIVIDER_MULT = 11` — можливо треба підібрати.

### Перевір піни газу
Роз'єм `+ACC–` (3 піни):
- Крайній = +5V (червоний)
- Середній = сигнал (зелений/білий)  
- Крайній = GND (чорний)

Виміряй мультиметром при відпущеному газі (~0.8V) і повному (~4.2V).
Якщо інші значення — відкоригуй `THROTTLE_ADC_MIN/MAX` в `throttle.c`.

### Перевір датчики Холла
При ручному обертанні колеса повинні змінюватись стани на PB6/PB7/PB8.
Перевір мультиметром або осцилографом.

## Призначення пінів GD32F103C8T6

| Пін  | Функція          | Роз'єм на платі    |
|------|------------------|--------------------|
| PA0  | ADC — Газ        | +ACC– (середній)   |
| PA1  | ADC — Батарея    | Внутрішній дільник |
| PA2  | Гальмо (вхід)   | Важіль гальма      |
| PA8  | PWM фаза A high  | Мотор              |
| PA9  | PWM фаза B high  | Мотор              |
| PA10 | PWM фаза C high  | Мотор              |
| PB13 | PWM фаза A low   | Мотор              |
| PB14 | PWM фаза B low   | Мотор              |
| PB15 | PWM фаза C low   | Мотор              |
| PB6  | Hall A           | Датчик Холла A     |
| PB7  | Hall B           | Датчик Холла B     |
| PB8  | Hall C           | Датчик Холла C     |

## Увага

Ця прошивка написана для відновлення самоката після випадкового стирання.
Використовуй на власний ризик. Перед першим тестом:
1. Підніми самокат на підставці (колесо не торкається землі)
2. Плавно натисни газ — перевір що мотор крутиться в правильному напрямку
3. Перевір гальмо — мотор має зупинятись миттєво
